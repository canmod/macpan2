# Zero Vector

Create a [`numeric`](https://rdrr.io/r/base/numeric.html) vector of all
zeros with names given by `x`

## Usage

``` r
mp_zero_vector(x, ...)
```

## Arguments

- x:

  Object representing the names of the output vector. Most commonly this
  will be a [`character`](https://rdrr.io/r/base/character.html) vector.

- ...:

  Passed on to S3 methods.
