# Lookup

Lookup a subset or factor index associated with a symbol, and return the
index associated with that symbol.

## Usage

``` r
mp_lookup(index, symbol)
```

## Arguments

- index:

  Index table (see
  [`mp_index`](https://canmod.github.io/macpan2/reference/mp_index.md)).

- symbol:

  Character string that could possibly be associated with a subset or
  factor of `index`.
