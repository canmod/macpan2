# Rename Index Columns

Rename Index Columns

## Usage

``` r
mp_rename(x, ...)
```

## Arguments

- x:

  An index with columns to be renamed.

- ...:

  Name-value pairs. The name gives the new name and the value is a
  character vector giving the old name.
