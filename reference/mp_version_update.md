# Version Update

Update a model specification so that it is compatible with the installed
version of `macpan2`.

## Usage

``` r
mp_version_update(spec)
```

## Arguments

- spec:

  Object produced by
  [`mp_tmb_model_spec`](https://canmod.github.io/macpan2/reference/mp_tmb_model_spec.md)
  or another function that produces the same type of object.
