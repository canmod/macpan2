# Data Frame Describing State Dependent Per-Capita Flow Rates

Data frame giving states that per-capita flow rates directly depend on.
This is intended for plotting diagrams and not for mathematical
analysis, in that it does not describe indirect dependence for flow
rates on state variables.

## Usage

``` r
mp_state_dependence_frame(spec)
```

## Arguments

- spec:

  Model specification from
  [`spec`](https://rdrr.io/r/stats/spectrum.html).
