# Link Functions and Transformation

- `mp_identity` - Identity transformation

&nbsp;

- `mp_log` - Log transformation

&nbsp;

- `mp_log1p` - Log1p transformation (i.e., `log(1 + x)`)

&nbsp;

- `mp_logit` - Logit transformation

&nbsp;

- `mp_sqrt` - Square-root transformation

## Usage

``` r
mp_identity

mp_log

mp_log1p

mp_logit

mp_sqrt
```
