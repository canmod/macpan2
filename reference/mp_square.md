# Self Cartesian Product

Self Cartesian Product

## Usage

``` r
mp_square(x, suffixes = c("A", "B"))
```

## Arguments

- x:

  An index.

- suffixes:

  Length-2 character vector giving suffixes that disambiguate the column
  names in the output.
